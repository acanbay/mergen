# Citing Mergen

If you use Mergen in academic work, please cite the software.

## Text citation

> Canbay, A. C. (2026). *Mergen: Multi-dimensional Experimental Run
> GENerator* (Version 0.1.1) [Computer software].
> https://doi.org/10.5281/zenodo.21420074

## BibTeX

```bibtex
@software{canbay2026mergen,
  author  = {Canbay, Ali Can},
  title   = {Mergen: Multi-dimensional Experimental Run GENerator},
  year    = {2026},
  version = {0.1.1},
  doi     = {10.5281/zenodo.21420074},
  url     = {https://github.com/acanbay/mergen}
}
```

## Machine-readable metadata

The repository root contains a
[`CITATION.cff`](https://github.com/acanbay/mergen/blob/main/CITATION.cff)
file with the same information in the Citation File Format. GitHub
renders it under the "Cite this repository" button, and reference
managers can import it directly.

The DOI above is the concept DOI
[10.5281/zenodo.21420074](https://doi.org/10.5281/zenodo.21420074),
which always resolves to the latest release. Each release also has its
own version DOI, listed on the Zenodo record; release 0.1.0 is
[10.5281/zenodo.21420075](https://doi.org/10.5281/zenodo.21420075).

When citing a specific analysis, please also record the Mergen version
and the random seed used, so the design can be reproduced exactly.
